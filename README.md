\# Student Grade System Using Python



\## Project Overview

This project was created as part of my Data Science learning journey using Python and Jupyter Notebook.



The system allows calculation and evaluation of student grades based on marks entered by the user.



\## Features

\- Accepts student marks input

\- Calculates total and average scores

\- Assigns grades based on performance

\- Displays student results
